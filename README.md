# 🪷 온라인 산사 (Virtual Zen Temple) - 웹 메타버스 베이스캠프

> 화제의 3D 가상 도량 **산사(SANSA)** 스타일의 웹 메타버스 스타터 프로젝트입니다.  
> 앱 설치나 로그인 없이 **웹 브라우저(모바일/PC) 링크 하나로 즉시 접속**할 수 있으며, 향후 AI 자연어(바이브 코딩)로 공간을 확장하기에 최적화된 모듈형 구조로 구축되었습니다.

---

## 🌟 구현된 기본 기능

1. **3D 환경 & 산사 감성 분위기**
   - 부드러운 산안개(Atmospheric Fog)와 따뜻한 오후 햇살(Directional Light & Soft Shadows)
   - 전통 한옥 대청마루(원목 데크, 원형 기둥, 팔작지붕 기와, 단청 포인트)
   - 화강암 디딤돌 산책로, 연못(수련과 연잎), 고풍스러운 소나무 군락
   - 불빛이 깜빡이는 석등, 향 연기가 피어오르는 향로, 바람에 흔들리는 풍경

2. **반응형 플레이어 & 조작계**
   - 귀여운 삿갓과 가사를 두른 동자승/수행자 3D 아바타
   - **PC 조작**: `WASD` 또는 방향키로 걷기 / `Space` 점프 / `E` 좌선(명상) / `C` 합장 인사
   - **모바일 조작**: 화면 좌측 하단 **가상 터치 조이스틱** + 우측 하단 **원터치 행동 버튼(합장/좌선/점프)**
   - 3인칭 추종 카메라 (마우스/화면 터치 드래그로 360도 자유 회전)

3. **내장 Web Audio 힐링 사운드 (외부 다운로드 필요 없음)**
   - 🪵 **목탁(Moktak) 소리**: 브라우저 오디오 신시사이저 기반 타격음
   - 🔔 **범종 / 싱잉볼(Singing Bowl)**: 깊은 저음과 풍부한 배음의 청동 종소리
   - 🎐 **은은한 풍경 소리(Wind Chimes)**: 바람에 맞춰 주기적으로 울리는 앰비언트 사운드
   - 👣 발걸음 소리

4. **산사 감성 UI**
   - 접속 시 자동 부여되는 고요한 이름 (예: `고요한 구름`, `맑은 바람`, `다정한 솔잎`)
   - 오늘의 화두(명상 지혜 메시지) 팝업
   - 목탁 치기 카운터 & 힐링 연출

## 🚀 로컬 실행 방법

터미널에서 아래 명령어를 실행하면 로컬 개발 서버가 시작됩니다:

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하면 공간에 바로 입장할 수 있습니다.  
같은 와이파이에 연결된 스마트폰에서도 터미널에 표시되는 `http://192.168.x.x:5173` 주소를 입력하면 즉시 접속하여 가상 조이스틱으로 조작해볼 수 있습니다.

## 🎨 바이브 코딩(Vibe Coding) 가이드

새로운 사찰 건물, 자연물, 상호작용 요소를 추가하고 싶을 때는 AI에게 아래 예시처럼 자연어로 요청하면 됩니다.

### 예시 프롬프트 1: "대청마루 옆에 3층 석탑 추가해줘"
> *"src/components/world/ 아래에 석조 재질의 3층 석탑(Pagoda) 컴포넌트를 만들고, Experience.tsx의 바닥 디딤돌 옆에 배치해줘. 탑 꼭대기에는 작은 금빛 상륜부를 달아줘."*

### 예시 프롬프트 2: "방석에 찻상과 따뜻한 김이 나는 찻잔 추가해줘"
> *"대청마루 위 방석 옆에 작은 목재 찻상과 김이 피어오르는 녹차 찻잔 컴포넌트를 만들어서 배치해줘. 클릭하면 차 마시는 효과음도 나게 해줘."*

### 예시 프롬프트 3: "밤/노을 모드로 바꾸는 버튼 추가해줘"
> *"우측 상단 UI에 해/달 아이콘 버튼을 추가하고, 클릭하면 Environment.tsx의 하늘과 조명이 주황빛 노을이나 별이 쏟아지는 밤하늘로 전환되게 해줘."*
